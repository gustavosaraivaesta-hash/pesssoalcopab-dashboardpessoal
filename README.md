# pesssoalcopab-dashboardpessoal

Crie um dashboard moderno, clean e intuitivo para analisar os militares da diretoria de Abastecimento. O dashboard deve conter filtros de Especialidade, Graduação, previsão de embarque por mensal, por SDP DAbM, mostrando (TMFT,	EXI, DIF)





O dashboard deve usar como base de dados essa planilha Google Sheets: https://docs.google.com/spreadsheets/d/1-k4hLJdPTvVl7NGl9FEw1WPhaPD5tWtAhc7BGSZ8lvk/edit?usp=sharing
